**MCP + A2A + Agent Memory + Context Engineering + Advanced RAG + Eval Engineering + vLLM**

A production-oriented enterprise AI platform combining modern agentic AI architecture with advanced retrieval and local LLM inference.

### Core Architecture

```text
                    ┌─────────────────────┐
                    │      User Query     │
                    └──────────┬──────────┘
                               ↓
                    ┌─────────────────────┐
                    │ Context Engineering│
                    └──────────┬──────────┘
                               ↓
               ┌───────────────┴───────────────┐
               ↓                               ↓
       ┌──────────────┐                 ┌──────────────┐
       │  A2A Agents  │                 │ Agent Memory │
       └──────┬───────┘                 └──────┬───────┘
              ↓                                ↓
       ┌──────────────┐                 ┌──────────────┐
       │ MCP Tools    │◄───────────────►│ Knowledge    │
       └──────┬───────┘                 │ Base / RAG  │
              ↓                         └──────────────┘
       ┌──────────────┐
       │ Hybrid RAG   │
       ├──────────────┤
       │ Dense Search │
       │ Keyword      │
       │ RRF          │
       │ Reranking    │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ LLM / vLLM   │
       └──────┬───────┘
              ↓
       ┌──────────────┐
       │ Evaluation   │
       └──────────────┘
```

### Key Results

* Hybrid retrieval with dense + keyword search
* Reciprocal Rank Fusion
* Cross-Encoder reranking
* Recall@5 improved from **50% → 100% after reranking**
* MCP server + MCP tools + client-server execution
* Short-term and long-term agent memory
* Context scoring, ranking, compression and token budgeting
* A2A Research, Retrieval and Evaluation agents
* Parallel execution and agent handoffs
* **15/15 A2A validation checks passed**
* LLM-as-a-Judge evaluation
* Hallucination detection
* vLLM OpenAI-compatible inference
* Batch/concurrent inference benchmarking
